# 老己 Triune Journal

> **本地优先 · 隐私守护 · 越用越懂你的 AI 情绪陪伴桌宠**

「老己」是一个跑在你**自己电脑上**的 AI 陪伴桌面宠物。它读你的日记、陪你聊天，越用越像你；但它**不联网、不收集、不上传**——你的心事只属于你。

---

## 为什么做这个

现在市面上的 AI 陪伴产品，本质都是「把你的秘密交给大公司，换一点陪伴」。

老己反过来了：**陪伴归你，秘密也归你。**

- 它用弗洛伊德「三我」模型（本我 / 自我 / 超我）组成内部对话，最后由「自我」拍板给你一句能落地的回应；
- 它内置「高情商」表达（借鉴「超会写」式共情），像朋友一样接住情绪、给台阶，而不是冷冰冰的机器人；
- 它完全本地运行，日记用 AES-256-GCM 加密落盘，端口只听 `127.0.0.1`，**任何人都无法从局域网或外网拖走你的数据**。

如果你在意隐私、又想要一个真正「懂你」的陪伴，这就是给自己的礼物。

---

## 核心特性

- 🔒 **本地优先 / 零云依赖**：所有对话与日记存储在本机，可选接入你自己的 LLM 接口（兼容 OpenAI 协议，支持硅基流动等免费/自建模型）。
- 🛡️ **信息安全防火墙**：
  - 后端仅绑定 `127.0.0.1`（拒绝局域网 / 公网访问）；
  - Host 白名单 + 安全响应头（CSP / `X-Frame-Options: DENY` / `X-Content-Type-Options: nosniff` / `Referrer-Policy: no-referrer`）；
  - 日记与画像数据 **AES-256-GCM 加密落盘**（密钥 `data/.tjkey` 不进版本库）。
- 🧠 **三我人格引擎**：本我（真实冲动）↔ 超我（理想尺度）先「争」一场，自我综合给出最终回复，不再是单向喇叭。
- 💬 **高情商表达**：每个「我」都注入了共情与「给台阶」的话术规则，不做评判、先接住情绪。
- 🖼️ **个性化顶部形象**：支持上传**图片 / GIF / 视频（MP4·WebM）**作为桌宠形象——GIF 与视频保留动态，存于本地 IndexedDB。
- 📓 **日记导入与画像**：可把别处写过的日记贴进来，老己越读越像你；支持按气质自适应话术。
- 📜 **完全开源（AGPL-3.0）**：代码可审计、可自托管、可自由修改分发。

## 隐私与安全承诺

| 维度 | 老己的做法 |
|---|---|
| 数据存储 | 全部在本机 `data/` 目录，AES-256-GCM 加密 |
| 网络暴露 | 仅 `127.0.0.1`，同 WiFi 其他人无法访问 |
| 第三方上传 | 默认**不**上传任何日记/画像；仅当你配置的 LLM 接口需要时才把对话文本发送给**你自己指定的**模型服务 |
| 密钥管理 | 加密密钥 `data/.tjkey` 与真实 `.env` 均被 `.gitignore` 忽略，**不会进入公开仓库** |
| 代码透明 | 开源可审计，无隐藏上报 |

> ⚠️ 若你配置的是**云端** LLM（如 OpenAI、硅基流动），对话内容会按该服务条款发送给对应厂商。想做到「物理级隐私」，请接入本地模型（如 Ollama / LM Studio 提供的 OpenAI 兼容接口）。

## 快速开始

### 环境要求
- Node.js ≥ 20
- 一个 OpenAI 兼容的 LLM 接口（推荐硅基流动免费额度，或本地 Ollama）

### 安装与运行

```bash
# 1. 克隆仓库
git clone <your-fork-url>
cd triune-journal

# 2. 安装依赖
npm install

# 3. 配置 LLM（交互式，会生成 .env）
npm run setup
# 或手动复制模板后填写：
cp .env.example .env
# 编辑 .env，填入 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL

# 4. 启动后端（本地 127.0.0.1:3000）
npm run dev

# 5. 启动桌宠窗口（另开一个终端）
npm run widget
```

> 开发态也可一键同启：`npm run widget:dev`。

打包为独立桌面应用：`npm run dist`（需提前 `npm run build`）。

老己支持你将任意**图片 / GIF / 视频**设为桌宠的「顶部形象」。

- 你上传的所有素材**仅存储在你本机**（浏览器 IndexedDB 或本地文件），不会上传到任何服务器，开发者无法访问。
- 素材的**版权与肖像权由上传者自行负责**。请勿上传你无权使用、或可能侵犯他人肖像权 / 著作权的素材（例如未获授权的明星写真、他人摄影作品）。
- 开发者不对用户上传内容承担任何法律责任，并保留在收到权利方通知后移除相关功能指引的权利。

## 架构简述

```
triune-journal/
├── electron/        # 桌面壳（静默启动、脱离 cmd 控制台）
├── src/
│   ├── api/         # Express 后端（127.0.0.1 绑定 + 防火墙中间件）
│   ├── storage/     # AES-256-GCM 加密落盘 + 本地存储适配
│   ├── agents/      # 本我 / 自我 / 超我 三人格引擎
│   └── core/        # 通信底模（含高情商表达规则）
├── public/          # 桌宠 UI（widget.html 等）
└── data/            # 本地数据（加密，已被 .gitignore 忽略）
```
