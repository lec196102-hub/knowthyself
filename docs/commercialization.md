# Triune Journal 商业化路径（Commercialization Path）

> 文档版本：v1.0 ｜ 编制日期：2026-07-27 ｜ 状态：草稿 · 待评审
> 关联文档：`docs/PRD.md`（市场需求）、`docs/architecture.md`（技术架构）
> 定位：在「已实现 MVP」与「PRD 路线图 M1–M4」之上，补一条从 0 到规模化的商业化路径。

---

## 0. 一句话策略

以**本地优先 + 隐私安全**为信任基石，以**「三我多视角 + 气质个性化」**为产品护城河，走
**「工具 → 陪伴 → 洞察」的渐进式 Freemium SaaS** 路线：
先验证留存与付费意愿，**再**扩展分发渠道与 B2B，绝不本末倒置地先收费。

---

## 1. 商业化前提判断（产品现在在哪）

### 1.1 已具备（可收费的"地基"雏形）
- 三我对话引擎（本我/自我/超我）+ 三层安全架构 ✅
- 气质渐进测试（每日 10 题、6 天答完、完成恭喜）✅
- 静态角色卡 + first-person self-model + onboarding 门禁 ✅
- Web 测试页 + Electron 桌宠 + 多 LLM 兼容 ✅
- 文件存储持久化 ✅

### 1.2 决定"能不能收费"的关键缺口
| 缺口 | 为何是商业化前提 | 当前状态 |
|------|------------------|----------|
| 账号体系 + 云端同步 | 付费必须绑定用户身份、跨设备；文件存储无法支撑多端 | ❌ Out of Scope |
| 商用安全记忆层（分层+矛盾失效） | **付费个性化的飞轮底座**；无长期记忆则"陪伴"只是单次体验 | ⏸ 已规划、延后 |
| 用户自述 → 三我语气演化 | 把"一次性角色卡"升级为"长期关系"，是 Pro 的核心卖点 | ⏸ 已规划、延后 |
| 正式前端 Web UI | 当前为测试页，影响转化与信任 | ❌ |
| 合规资质（ICP/算法备案/等保） | 国内经营性与生成式 AI 服务的硬性门槛 | ❌ |
| 支付接入 | 收费的唯一通道 | ❌ |

> **核心判断**：现在**还不能收费**。先走一个付费前的「价值验证期」，把记忆层与个性化演化做出来——这既是留存飞轮，也是未来的付费墙。

## 2. 价值假设与验证（0–3 月，不急着收费）

**北极星指标**：周活跃日记条目数（WJE，取自 PRD §4.1）。

### 待验证的三条核心假设
1. **多视角 > 单回复**：三我比一个"官方正确"的回复更能让人想继续写（看 7 日留存差异）。
2. **气质调制有效**：用户主观"被懂"感显著提升（用 NPS / 满意度埋点验证）。
3. **每天回来**：6 天渐进测试本身就是一场留存实验——能否把"答完 60 题"变成"每天打开 App"。

### 本阶段动作
- 完成**商用安全记忆层**（SQLite + 分层 + 矛盾失效）。
- 接通**用户自述 → 三我语气演化**数据流，让角色随使用"越长越像你"。
- 做正式 Web UI（替换测试页），保留桌宠作为差异触点。
- 小范围种子用户（心理学社区 / 豆瓣小组 / 自我成长类小红书），守住内容安全底线。
- 埋点：WJE、7 日留存、气质测试完成率（PRD 目标 ≥40%）、三我回复成功率（≥99%）。

## 3. 变现模型（Freemium SaaS）

### 3.1 梯度（中国市场定价建议）
| 档位 | 价格 | 包含 |
|------|------|------|
| **免费版** | ¥0 | 每周限量条目、基础三我、单气质、本地存储 |
| **Pro** | ¥18/月 或 ¥128/年 | 无限条目 · 长期记忆与个性化演化 · 多端云同步 · 年度心理回顾 · 导出 · 优先算力 |
| **增值/一次性** | ¥39/份 | 深度洞察报告、年度回顾精装卡 |

### 3.2 关键定价决策
- **为什么订阅而非买断**：LLM 推理有持续边际成本，订阅更可持续，也绑定长期关系。
- **为什么不接广告**：情绪日记是高度敏感场景，广告会摧毁信任，且触碰《个人信息保护法》敏感信息红线。
- **免费版的"钩子"**：长期记忆与个性化演化放在 Pro——这是前面延后的记忆层，天然成为付费墙。
- **支付**：国内微信支付 / 支付宝（需企业主体 + 增值电信许可）；海外 Stripe。

## 4. 分阶段商业化路线图（核心）

| 阶段 | 时间窗 | 范围 | 退出标准（指标） |
|------|--------|------|------------------|
| **P0 价值验证** | 0–3 月 | 记忆层 + 个性化演化 + 正式 UI + 种子用户 | WJE 周环比上升；7 日留存 ≥25% |
| **P1 收费上线** | 3–6 月 | 账号+云同步 · 支付 · 合规资质 · Freemium 上线 | 付费转化率、ARPU 可观测；合规齐全 |
| **P2 护城河深化** | 6–12 月 | 长期记忆飞轮 · 年度回顾（裂变）· 洞察报告付费 | 年留存、口碑转介绍占比提升 |
| **P3 分发扩展** | 12–18 月 | IM（企业微信/公众号）· 桌宠病毒 · 内容社区 | IM 渠道新增条目占比 ≥30% |
| **P4 企业/机构** | 18 月+ | B2B 白标（心理咨询机构 / EAP 员工帮助计划） | 签约机构数、白标部署数 |

> 与 PRD 里程碑对齐：P0≈M2 体验增强，P1≈M3 平台扩展前提，P2/P3≈M4 数据与企业化，P4 为 PRD 之外的企业化延伸。

## 5. 合规与风险（中国，商业化生死线）

| 主题 | 要求 / 动作 |
|------|-------------|
| **避免被认定为"医疗/诊疗"** | 话术坚持「陪伴 / 记录 / 自我觉察」，**不承诺治疗效果、不输出诊断**；这是避开医疗器械监管的关键 |
| **生成式 AI 服务** | 完成算法备案；深度合成内容需显著标识 |
| **经营资质** | ICP 备案 + 增值电信业务经营许可证（经营性付费服务）；等保（网络安全等级保护） |
| **数据隐私（PIPL）** | 日记属敏感个人信息：单独同意、最小必要、可删除；**本地优先是加分项**；跨境需安全评估 |
| **依赖许可** | 当前 `package.json` 为 ISC（商用友好，等同 MIT）；若走闭源商业版需确认无 GPL 污染；**延后的记忆层必须自研**，不引入 PolyForm 等非商用协议代码（参考 nemos 教训） |
| **内容安全** | 三层架构已建，需定期审计规则 + 用户申诉通道，避免误杀引发投诉 |

## 6. 单位经济与增长（草算）

- **假设**：Pro ¥128/年；付费率 5%；社区/内容获客 CAC ≈ ¥30；7 日留存 25% → 目标年留存。
- **LTV ≈ ARPU ÷ 年流失率**；年度回顾分享卡是低成本裂变，可显著压低 CAC。
- **边际成本**：LLM token + 存储，需多模型路由 / 缓存 / 长记忆摘要来控本。
- **增长杠杆**：① 年度回顾可分享卡片（裂变）；② 桌宠常驻（自然曝光）；③ 心理学/自我成长社区口碑；④ 转介绍激励。
